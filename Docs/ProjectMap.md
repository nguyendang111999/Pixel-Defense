# Pixel Defense — Project Map

Pixel Flow-style color cannons meet tower defense: a dragon made of colored cube scales crawls along a spiral toward the base in the center. Tap the front cannon of a column to send it to a base slot; it fires at the dragon's **front-most scales of its own color**. Destroy every scale to win. If the head touches the base for **2 consecutive seconds**, the base is lost.

## Scene

| Scene | Purpose | Entry point |
|---|---|---|
| `Assets/Scenes/Game.unity` | The only scene: home screen, every level, results. Rebuilt from code by **Pixel Defense ▸ Rebuild Game Scene** — don't edit it by hand. | `PixelDefense.App.GameFlow` on `App` |

Scene objects (all created by `EditorTools/Assets/SceneBuilder.cs`):

| Object | Components | Role |
|---|---|---|
| `Main Camera` | `Camera`, `CameraRig` | Auto-frames arena + tray for any aspect ratio; shake, FOV kicks, cinematic push-ins. |
| `Sun` | `Light` | Soft-shadow key light. Ambient is trilight (set in the scene's lighting). |
| `Post` | `Volume` (`Assets/Settings/PixelDefensePost.asset`) | Bloom, neutral tonemapping, vignette, color grade. |
| `Battle` | `BattleView`, `ToyLook` | Runs a level: model, views, input → deploys, juice. Pushes toy-lighting shader globals. |
| `UI` | `UIDocument` (`Assets/UI/Game.uxml`, `PanelSettings.asset`), `GameUi` | All UI Toolkit screens. |
| `App` | `GameFlow`, `AudioService`, `PointerInput` | Composition root and state machine. |

## Screens and popups (UI Toolkit, `Assets/UI/Game.uxml`)

| Screen | Element | Controller | Shown by |
|---|---|---|---|
| Home (title, level, PLAY) | `#home` | `UI/HomeView` | `GameFlow.EnterHome` (live 3D board of the next level behind it) |
| Battle HUD (level, coins, dragon health bar, boosters, praise, jam banner, tutorial bubble + hand, danger vignette) | `#hud` | `UI/HudView` | `GameFlow.EnterPlaying` |
| Result (victory / base lost) | `#resultOverlay` | `UI/ResultView` | `GameFlow.OnBattleFinished` |
| Settings / pause | `#settingsOverlay` | `UI/SettingsView` | gear buttons, Android back |

Styles: `Assets/UI/Styles/Theme.uss` (tokens, buttons, fonts) and `Game.uss` (layout). Icons and the health bar are Painter2D custom elements (`UI/Elements`).

## Game flow

`Home → Playing → Result → (Next / Try again → Playing) | Home`, owned by `GameFlow`. Pausing sets `Time.timeScale = 0`; the battle model only advances in `BattleView.Update`, so it pauses too.

## Data

| Data | Location | Notes |
|---|---|---|
| Levels | `Assets/Levels/main.txt` (TextAsset on `GameConfig`) | Text format documented on `Core/LevelParser`. Generated by **Pixel Defense ▸ Levels ▸ Generate Campaign** (L01 is hand-written in the generator). Every level is proven solvable and bot-beatable by `Tests/EditMode/ShippedLevelsTests`. |
| Rules tunables | `Assets/Config/GameConfig.asset` → `Battle` (`Core/BattleSettings`) | Fire rate, flight time, contact lose time (2 s), recoil, enrage, boosters, economy. |
| Look & layout | `Assets/Config/VisualConfig.asset` (`Gameplay/VisualConfig`) | Palette, dragon skins, sizes, materials, juice values. |
| Sounds | `Assets/Config/AudioLibrary.asset`, clips in `Assets/Audio` | Synthesized placeholders (`EditorTools/Audio`); swap clips in the library freely. |
| Save | `persistentDataPath/progress.json` (`App/ProgressData`) | Level id, level number, coins, boosters, stars. Settings toggles in PlayerPrefs. |
